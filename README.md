👗 The Wee Wardrobe – Children’s Clothing Brand Website
🌟 Project Overview

The Wee Wardrobe is a stylish and creative children’s clothing brand website developed using HTML5 and CSS3. The website is designed to provide a colorful, attractive, and user-friendly experience for users exploring kids’ fashion collections.

This project was created as part of my web development learning journey during my BCA 2nd Year at Dezyne Ecole College, Ajmer. The website focuses on clean design, organized layouts, responsive sections, and smooth user interaction.

👩‍💻 About Me

Hi, I’m Harshita Verma, a BCA student passionate about learning web development and Android programming. This project helped me improve my frontend development skills and understand how modern websites are designed and structured.
